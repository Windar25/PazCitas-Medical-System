# 🏥 PazCitas - Sistema de Gestión de Citas Médicas

**PazCitas** es una solución de software integral para la automatización de citas médicas ambulatorias. El sistema fue diseñado para optimizar el flujo operativo clínico mediante una arquitectura distribuida robusta.

---

## 🚀 Características Principales

* **Gestión de Citas:** Registro, modificación y cancelación de citas médicas en tiempo real.
* **Integridad Transaccional:** Uso de Stored Procedures en SQL para garantizar la consistencia de datos críticos.
* **Reportes Operativos:** Generación automática de reportes de productividad médica.
* **Validación de Negocio:** Lógica encapsulada en el Backend para evitar conflictos de horarios y duplicidad.

---

## 🛠 Tech Stack

Este proyecto implementa una arquitectura **Cliente-Servidor Distribuida**:

* **Backend:** Java (Lógica de Negocio, POO, Persistencia).
* **Frontend:** C# .NET (Interfaz de Usuario Windows Forms/WPF).
* **Base de Datos:** SQL Server / MySQL (Diseño físico, Normalización, Stored Procedures).
* **Ingeniería:** UML (Arquitectura de Software) y BPMN (Modelado de Procesos).

---

## 📂 Estructura del Proyecto

El código sigue patrones de diseño y una separación clara de responsabilidades:
* `/BackEnd` - Lógica de negocio y conexión a datos (Java).
* `/FrontEnd` - Interfaz gráfica de usuario (C#).
* `/Base de Datos` - Scripts SQL y diagramas entidad-relación.
* `/UML` - Documentación de arquitectura y diseño.
